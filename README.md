# Top Hotel Property Management System (PMS) Ecosystem

**Curated List of SaaS Products & Open-Source GitHub Projects**  
*Focused on Hotel Property Management, Reservations, Front Desk, Housekeeping, Guest Operations & Hospitality Automation*  
**Last updated: August 2026**

This repository tracks notable **SaaS/Hosted platforms** and **open-source projects** for **Hotel Property Management Systems (PMS)**. These systems help hotels, resorts, hostels, serviced apartments, vacation rentals, and other accommodation businesses manage reservations, room inventory, front-desk operations, check-in/check-out, housekeeping, guest profiles, billing, payments, reporting, channel management, and hotel operations.

**Examples** include Cloudbeds, Mews, Oracle OPERA, Guesty, Little Hotelier, Hotelogix, eZee Absolute, RMS Cloud, Stayntouch, RoomRaccoon, WebRezPro, SIHOT, HotelKey, and innRoad.

**Open-source emphasis**: This section is heavily expanded with active open-source hotel PMS, reservation, booking-engine, hotel-management, hospitality ERP, and accommodation-management projects — ideal for hotels, developers, researchers, and operators looking to self-host, customize workflows, integrate hotel hardware, or build their own hospitality technology stack.

Contributions welcome! Open a PR to add/update entries. Keep descriptions factual and link to official sites.

### Additional Strong Open-Source Options

- **QloApps** for a comparatively mature open-source hotel PMS + booking engine + hotel website stack. :contentReference[oaicite:6]{index=6}
- **HotelDruid** for traditional self-hosted hotel reservation and property-management workflows.
- **Open Hotel PMS** for a modern Next.js/Supabase architecture and operations-oriented hotel workflows. :contentReference[oaicite:7]{index=7}
- **Pesan PMS** for a modern open-source PMS aimed at hotels, homestays, villas, and multi-property accommodation businesses. :contentReference[oaicite:8]{index=8}
- **Kamra PMS** for an emerging AI-native PMS architecture with MCP/agent integration. :contentReference[oaicite:9]{index=9}
- **Frappe/ERPNext** for building a broader hospitality ERP around an open-source business platform.
- **Odoo** for organizations wanting to combine hotel-specific modules with accounting, CRM, POS, inventory, website, and business automation.
- **GitHub hotel-PMS projects** for smaller experimental, educational, and specialized property-management systems.

**Frameworks for building custom hotel PMS systems**: Combine **QloApps**, **HotelDruid**, **Open Hotel PMS**, **Frappe/ERPNext**, **PostgreSQL/MySQL**, **Redis**, **Keycloak**, **Next.js**, **React**, **Supabase**, **Grafana**, and **n8n** to create a self-hosted hospitality technology stack.

A modern open-source hotel architecture can therefore separate the stack into:

1. **Property Management** — QloApps, HotelDruid, Open Hotel PMS
2. **Reservations & Booking Engine** — QloApps, Open Hotel PMS, Pesan PMS
3. **Front Desk** — Open Hotel PMS, Kamra PMS, QloApps
4. **Housekeeping** — Open Hotel PMS, Kamra PMS, custom Frappe/Odoo workflows
5. **Guest Management** — QloApps, Open Hotel PMS, Pesan PMS
6. **Billing & Accounting** — ERPNext, Odoo, Frappe
7. **Online Payments** — Stripe/Adyen integrations, custom payment gateways
8. **Channel Management** — custom APIs and channel-manager integrations
9. **Guest Communication** — Chatwoot, Rocket.Chat, WhatsApp integrations
10. **Analytics** — Grafana, Metabase, Apache Superset
11. **Workflow Automation** — n8n, Node-RED, Frappe workflows
12. **Identity & Access Management** — Keycloak, Authentik
13. **AI/Agent Layer** — Kamra PMS/MCP, Ollama, LangGraph, custom hotel agents

## How to Contribute

1. Fork the repo.
2. Add/edit entries in `README.md` (follow existing format).
3. Include: name, link, 1–2 sentence description, and whether it's SaaS or open-source.
4. Prioritize actively maintained projects with meaningful PMS, reservation, hotel-management, booking-engine, front-desk, housekeeping, guest-management, or hospitality-automation functionality.
5. Verify the project's current license before describing it as open source.
6. Submit a PR with a short explanation.

Star the repo if you find it useful!

## Disclaimer

- This is a **community-curated list** — not exhaustive and not an endorsement.
- Commercial hotel PMS platforms and open-source projects have substantially different feature sets, deployment models, integrations, scalability, support models, and hospitality-specific functionality.
- Some projects listed here are broader ERP, CRM, booking, reservation, or business-management platforms rather than dedicated hotel PMS products.
- GitHub contains many small hotel-management projects that may be experimental, educational, incomplete, or inactive; repository inclusion does not imply production readiness.
- Open-source licensing varies between projects; always verify the current license and any enterprise/community-edition restrictions before deployment.
- Self-hosted hotel PMS systems require appropriate engineering for backups, security, PCI/payment compliance, availability, data protection, upgrades, monitoring, and operational support.
- Hotel systems handling guest identity, payment, passport/ID information, and other sensitive data should be deployed with appropriate security and privacy controls.
